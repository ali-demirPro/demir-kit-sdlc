# Envision questionnaire — brownfield (lite)

Use with **`kit-envision`** when repo already has product code. Skip full greenfield Q&A; still produce `discovery-brief` + **`discovery-approved`**.

Full greenfield list: `envision-questionnaire.md`.

## Required (batch in one message)

1. **Direction delta:** What changes in the next 90 days vs today?
2. **ICP / promise:** Still accurate? One-line update if not.
3. **Platform:** Stay on current stack or explore pivot? (options)
4. **Scope guard:** Top 3 “will not do now” items.
5. **Risks:** Biggest technical or market risk **in this repo**.

## Research minimum (lite)

6. **Competitors:** Name ≥2 alternatives or categories (can be brief).
7. **Legal / compliance:** PII, payments, health, kids, EU/US store rules — or “none identified” + data you store.

## Repo

Agent still fills **§ Repo snapshot** from scan; council sections may be shorter but **≥2 architecture options** only if user is considering pivot.

## Handoff

Same § Handoff to SDLC as full envision (`commercial_covered`, `architecture_covered`, `waived_baselines` rules in `envision-handoff.md`).
