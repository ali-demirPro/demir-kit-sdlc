# How

1. Sürüm kapsamını ve hedef dağıtımı oku.
2. Versiyon/changelog/store metadata eksiksiz mi?
3. Release checklist: imza, build, privacy, fiyat, yaş, lisans.
4. Rollout: kademeli mi, geri dönüş planı var mı?
5. `REL-*` bulguları; verdict `go` | `no_go`.
6. İnsan kapısına kanıt paketi + tek soru.

## Contract
- **Input:** leaf/closure, store metadata, build, dağıtım hedefi.
- **Output:** release checklist, `REL-*`, go/no-go, rollback planı.
- **Done when:** tüm zorunlu maddeler kanıtlı; insan kapısı hazır.
- **Forbidden:** store submit, fiyat değişimi, insan onayı yerine geçmek.
- **Handoff:** marketing/stores, devops, insan.
