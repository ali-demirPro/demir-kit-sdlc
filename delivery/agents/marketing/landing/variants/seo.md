# Marketing / Landing — SEO / Analytics / i18n

**Capabilities:** `domain.analytics`, `domain.i18n`, `quality.performance` · **Min level:** expert (analytics/performance) / practitioner (i18n)
**Gate:** `commercial`

## Kapsam

Arama görünürlüğü, ölçüm ve çok dilli landing tutarlılığı.

## Yöntem

1. **Niyet:** hangi sorgu, hangi sayfa? Bilgi/karşılaştırma/satın alma.
2. **Başlık/meta:** benzersiz title, description, H1; anahtar kelime doğal.
3. **Yapı:** başlık hiyerarşisi, iç link, canonical, sitemap, robots.
4. **Schema:** Organization/Product/FAQ/Article; doğru alanlar.
5. **i18n:** `hreflang`, locale URL, çeviri kalitesi, kültürel uyum.
6. **CWV:** LCP/INP/CLS; font/script stratejisi.
7. **Analytics:** organic landing → CTA → conversion; UTM.
8. **Tazelik:** içerik eskime, kırık link, sıralama takibi.

## Kanıt

- Keyword→page matrisi.
- Metadata/schema diff'i.
- hreflang/locale kontrolü.
- CWV raporu.
- Analytics event/funnel.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Intent | Sorgu↔sayfa uyumu |
| Metadata | Benzersiz + doğal |
| Yapı | Canonical/sitemap |
| Schema | Doğru tip/alan |
| i18n | hreflang/locale |
| CWV | Budget içinde |

## Anti-pattern'ler

- Aynı title'ı tüm sayfalara koymak.
- Keyword stuffing.
- `hreflang`'i unutmak.
- Schema'yı yanlış type ile işaretlemek.
- CWV'yi SEO'dan bağımsız sanmak.

## Handoff

Developer'a: metadata/schema/CWV.
Growth/run'a: funnel/deney.
Landing'e: içerik hizası.
