# Marketing / Stores — ASO / Analytics / i18n

**Capabilities:** `domain.analytics`, `domain.i18n`, `quality.privacy`, `distribution.web` · **Min level:** practitioner
**Gate:** `commercial`

## Kapsam

Store keşfi, dönüşüm, analitik ve lokalizasyon; web/store mesajının tutarlılığı.

## Yöntem

1. **Anahtar kelime:** niyet (keşif/marka/rakip), hacim, zorluk; başlık+alt başlık.
2. **Dönüşüm:** ikon, ilk 3 screenshot, kısa açıklama, derecelendirme.
3. **Deney:** App Store product page optimization / Play experiments; tek değişken.
4. **Analytics:** store impression → ürün sayfası → install → activation funnel.
5. **Lokalizasyon:** anahtar pazarlar; metin uzunluğu; kültürel uyum.
6. **Privacy:** store mesajı ↔ privacy label ↔ data safety tutarlı.
7. **Web/store:** landing mesajı ile store metni aynı değer önerisi.
8. **Ölçüm:** UTMs, campaign attribution, install source.

## Kanıt

- Anahtar kelime/rakip tablosu.
- Deney planı + sonuç.
- Funnel/attribution tanımı.
- Lokalizasyon matrisi.
- Privacy tutarlılık kontrolü.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Keyword | Niyet + başlık uyumu |
| Conversion | İlk 3 görsel + metin |

| i18n | Anahtar pazar |

## Anti-pattern'ler

- Anahtar kelime spam'i.
- Aynı anda 5 değişken denemek.
- Install'ı activation sanmak.
- Store metnini makine çevirisiyle bırakmak.
- Privacy label ile reklam metnini çeliştirmek.

## Handoff

Apple/Google variant'larına: metadata girdisi.
Landing'e: mesaj hizası.
Growth/run'a: funnel/deney.
