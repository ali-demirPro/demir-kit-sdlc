# Marketing / Stores — Google

**Capabilities:** `platform.android`, `distribution.play` · **Min level:** practitioner (platform) / expert (store)
**Gate:** `platform`, `commercial`, `human` (submit)

## Kapsam

Play listing, data safety, içerik derecelendirmesi, görseller ve kademeli
rollout.

## Yöntem

1. **Metadata:** uygulama adı (30), kısa açıklama (80), tam açıklama (4000);
   anahtar kelime doğal kullanım.
2. **Görseller:** telefon/tablet/foldable setleri; ilk 3 görselde değer önerisi.
3. **Data safety:** toplanan/ paylaşılan veri gerçek akışla aynı; şifreleme.
4. **İçerik derecelendirmesi:** anket doğru; hedef yaş.
5. **Track:** internal → closed → open; test kullanıcıları.
6. **Rollout:** %5→%20→%100; durdurma eşiği.
7. **ASO:** başlık/kısa açıklama/anahtar kelime; rakip analizi.
8. **Lokalizasyon:** anahtar pazarlar; fiyat/vergi.
9. **Pre-launch:** crash/ANR raporu temiz.

## Kanıt

- Metadata taslağı (limitlerle).
- Görsel setleri.
- Data safety formu.
- Track/rollout planı.
- Pre-launch raporu.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Metadata | Limit + anlam |
| Görsel | Cihaz seti |
| Data safety | Gerçek akış |
| Track | Kademeli |
| Pre-launch | Crash/ANR yok |
| Rollout | %5→%100 + rollback |

## Anti-pattern'ler

- Data safety'yi boş bırakmak.
- Yalnız telefon screenshot'ı.
- %100 rollout'u test etmeden açmak.
- İçerik derecelendirmesini yanlış doldurmak.
- Pre-launch raporunu okumamak.

## Handoff

Release'e: track/rollout.
Security/Privacy'ye: data safety.
Landing'e: mesaj hizası.
