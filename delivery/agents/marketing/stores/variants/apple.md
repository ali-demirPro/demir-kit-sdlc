# Marketing / Stores — Apple

**Capabilities:** `platform.ios`, `distribution.app_store` · **Min level:** practitioner (platform) / expert (store)
**Gate:** `platform`, `commercial`, `human` (submit)

## Kapsam

App Store görünürlüğü, metadata bütünlüğü, görsel set, privacy label ve inceleme
riski.

## Yöntem

1. **Metadata:** ad (30), alt başlık (30), anahtar kelime (100), açıklama (4000),
   promosyon metni (170); karakter ve anlam kontrolü.
2. **Görseller:** cihaz setleri, ilk 3 screenshot'ın değer önerisi; metin okunur.
3. **Privacy:** App Privacy label'ları gerçek veri akışıyla aynı; ATT açıklaması.
4. **Yaş/İçerik:** doğru derecelendirme; IAP ve abonelik açıklaması.
5. **İnceleme:** demo hesap, not, ödeme testi; red nedenleri önceden kontrol.
6. **Lokalizasyon:** anahtar pazarlar; metin taşması; fiyat/vergi.
7. **ASO:** anahtar kelime ↔ başlık ↔ ekran; rakip analizi.
8. **Yayın:** phased release; rollback planı.

## Kanıt

- Metadata taslağı (karakter sayısıyla).
- Screenshot/preview seti.
- Privacy label ↔ data map.
- İnceleme notu + demo hesap.
- Phased release planı.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Metadata | Limit + anlam |
| Görsel | Cihaz seti + değer önerisi |
| Privacy | Label = gerçek akış |
| İnceleme | Demo/not hazır |
| Lokalizasyon | Anahtar pazar |
| Yayın | Kademeli + rollback |

## Anti-pattern'ler

- Anahtar kelime doldurmak.
- Privacy label'ı "sonra" doldurmak.
- Aynı screenshot'ı tüm cihazlara koymak.
- Demo hesap olmadan submit.
- Reddedilen build'i açıklamasız tekrar göndermek.

## Handoff

Release'e: metadata + build.
Security/Privacy'ye: veri akışı.
Landing'e: store mesajı ↔ site mesajı.
