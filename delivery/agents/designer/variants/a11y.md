# Designer — Accessibility

**Capability:** `quality.a11y` · **Min level:** expert
**Packs:** `apple-a11y`, `web-ux`
**Gate:** `ui_visual`, `ui_interaction`, `comparison_valid`

## Kapsam

WCAG/HIG/Material erişilebilirlik kurallarını tasarıma gömmek: algı, etkileşim,
anlama ve dayanıklılık.

## Yöntem

1. **Kontrast:** metin/ikon/kenar; AA (gerekliyse AAA) hedefi.
2. **Odak:** görünür focus, sıra, tuzak yok, atlama linki.
3. **Klavye:** tüm akış klavyeyle; özel kısayol çakışması yok.
4. **Ekran okuyucu:** anlamlı sıra, label/trait, canlı bölge, hata ilişkisi.
5. **Boyut:** Dynamic Type/font scale 2.0; dokunma hedefi ≥44pt/48dp.
6. **Hareket:** `prefers-reduced-motion`/Reduce Motion; animasyon kapatılabilir.
7. **Form:** etiket, yardım, hata, zorunlu alan; renk tek başına anlam taşımaz.
8. **Medya:** altyazı/transkript; otomatik oynatma yok.

## Kanıt

- Kontrast tablosu (renk/AA).
- Focus sırası + klavye turu.
- VoiceOver/TalkBack notu.
- Font scale/Dynamic Type screenshot'ı.
- A11y audit checklist'i.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Kontrast | AA |
| Focus | Görünür + sıralı |
| Klavye | Tüm akış |
| Ekran okuyucu | Anlamlı |
| Boyut | 2.0/44pt+ |
| Hareket | Azaltılabilir |

## Anti-pattern'ler

- `outline: none`.
- Renkle tek başına durum bildirmek.
- Placeholder'ı label sanmak.
- Animasyonu zorunlu kılmak.
- "Sonra a11y turu" demek.

## Handoff

Developer'a: semantik/focus/ölçü notu.
Tester'a: klavye/VoiceOver/font scale senaryoları.
