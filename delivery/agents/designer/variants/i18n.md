# Designer — i18n

**Capability:** `domain.i18n` · **Min level:** practitioner
**Gate:** `ui_visual`, `ui_interaction`, `comparison_valid`

## Kapsam

Çok dilli arayüz: metin genişlemesi, RTL, çoğul/cinsiyet, biçim ve tipografi.

## Yöntem

1. **Genişleme:** EN→DE/RU +%30–40; buton/kart/etiket taşması.
2. **RTL:** yön, ikon, ok, hizalama; sayı/URL LTR kalır.
3. **Çoğul:** 0/1/2/çok; dil kuralları; cinsiyet.
4. **Biçim:** tarih, saat, para, sayı, adres, telefon.
5. **Tipografi:** dil fontu, fallback, satır yüksekliği.
6. **Kısaltma:** kısaltma/baş harf kültüre uygun mu?
7. **Görsel:** metin içeren görselde lokalize katman.
8. **Test:** pseudo-locale + anahtar pazar.

## Kanıt

- Locale matrisi.
- Uzun metin/RTL screenshot'ı.
- Çoğul/biçim örnekleri.
- Pseudo-locale notu.

## Gate rubriği

| Kriter | Pass |
|--------|------|
| Genişleme | +40% taşma yok |
| RTL | Yön/ikon doğru |
| Çoğul | Dil kuralı |
| Biçim | Locale |
| Font | Fallback |
| Test | Pseudo-locale |

## Anti-pattern'ler

- Metni görsele gömmek.
- Sabit genişlikli buton.
- "Bir çeviri yeter" demek.
- RTL'i ayna almakla çözmek.
- Tarih formatını elle yazmak.

## Handoff

Developer'a: locale/çoğul/biçim.
Tester'a: RTL/uzun metin.
Marketing'e: anahtar pazar metni.
