# How

1. design-md / tokens güncelle.
2. ui-gate: prototype vs uygulama karşılaştır.

## Contract
- **Input:** design refs, `ui_scope`, prototype.
- **Output:** design diff, UI gate evidence.
- **Done when:** visual + interaction reviewers pass.
- **Forbidden:** implementation, self-approval.
- **Handoff:** developer.
